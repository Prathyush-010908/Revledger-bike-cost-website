# 🏍️ BikeFinder — Bike Search & Ownership Cost Calculator

A modern and user-friendly web application that helps users **search for bikes, explore their specifications, check mileage and pricing, and estimate their monthly ownership expenses**.

.

🌐 Live Website
[View Website Here]https://claude.ai/public/artifacts/ed920327-4873-418d-acf9-a75756fe4dd9

This project was created as part of my journey into **web development and software development**, with a focus on building something practical and useful.

## ✨ Features

* 🔍 Search for bikes by name
* 🏍️ Browse popular bikes and models
* 📋 View detailed bike specifications
* ⛽ Check estimated mileage
* 💰 View estimated bike pricing
* 🧮 Calculate monthly fuel expenses
* 🏦 Estimate monthly EMI
* 🔧 Estimate maintenance and insurance costs
* 📊 View monthly ownership cost breakdown
* ⚖️ Compare multiple bikes
* 🎯 Filter bikes by price, engine capacity, mileage, brand, and type
* ❤️ Save favorite bikes
* 🕐 View recently searched bikes
* 🌙 Dark mode
* 📱 Fully responsive design for mobile, tablet, and desktop

## 💡 How It Works

The main user journey is:

**Search → Select Bike → Explore Specifications → Enter Usage Details → Calculate Monthly Cost → Compare Bikes**

Users can enter details such as:

* Monthly riding distance
* Petrol price
* Down payment
* Loan interest rate
* Loan tenure
* Maintenance expenses

The website then provides an estimated monthly ownership cost.

## 🧮 Monthly Cost Calculation

The estimated monthly cost can include:

* Fuel
* EMI
* Insurance
* Maintenance
* Service
* Other expenses

### Fuel Cost Formula

```text
Monthly Fuel Cost =
Monthly Distance ÷ Mileage × Fuel Price
```

The calculator updates the estimated cost based on the user's inputs.
